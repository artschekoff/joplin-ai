Joplin AI Assistant plugin for Joplin desktop. Purpose: integrate AI chat/editing into notes, with tool-driven note operations, diff review before applying body edits, streaming chat responses, optional web search, and image generation. Tech stack: TypeScript, Joplin plugin API, webpack, Jest, ESLint, Prettier. Main source areas: src/panel.ts (plugin panel/backend message bridge), src/webview/* (chat UI), src/ai/* (provider integrations, prompt building, streaming, cost/context handling), src/actions/* (tool handlers such as update_note/search_notes/create_note), src/settings.ts (plugin settings).
